# Nishi Verma | Civil Engineer Portfolio

One-page portfolio for a civil engineer with 8+ years in water, road and public building delivery, relocating to Ireland.

Live site: https://YOURUSERNAME.github.io/nishi-verma-portfolio/

## Files
- `index.html` is the whole site (HTML and CSS in one file).
- `images/` holds the project photos. Each project uses two images:
  `jjm-1.jpg`, `jjm-2.jpg`, `programme-1.jpg`, `programme-2.jpg`,
  `private-1.jpg`, `private-2.jpg`, `paper-1.jpg`, `paper-2.jpg`.
  Until a file is added, the page shows a grey hatched placeholder.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Publish
1. Create a public repository named `nishi-verma-portfolio` on github.com.
2. Upload everything in this folder, including the `images` folder.
3. Settings, then Pages, then "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Wait a minute or two, then open the live site link above.

## Before you publish
- Remove confidential drawings, rates and client names from any image.
- Keep each image under about 500 KB.
