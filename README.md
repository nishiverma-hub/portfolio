# Civil & Infrastructure Portfolio Website

A responsive dark-theme portfolio inspired by your screenshot.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub to display the published URL.

## Customize first
Replace `YourName`, `Your Name`, the email address, LinkedIn/GitHub links, profile-photo placeholder and project descriptions with your real details. Add only work samples you have permission to share.
